# Bot for Roguelike — помощник по Balatro

Бот-советник для [Balatro](https://www.playbalatro.com/): читает состояние текущего рана и
показывает ранжированный список ходов с точной разбивкой счёта — какие карты играть,
что сбрасывать, что покупать в магазине.

Игрок играет сам и выбирает. Бот считает и объясняет, из чего сложилось число.

## Статус

Планирование. Кода пока нет — см. **[PLAN.md](PLAN.md)**.

## Коротко о подходе

- **Ядро** — точный симулятор подсчёта очков Balatro на Python (счёт совпадает с игрой
  до единицы, проверяется golden-тестами).
- **Солвер** — полный перебор подмножеств руки + оценка матожидания сброса методом
  Монте-Карло по известному составу колоды.
- **Источник состояния** — сменные адаптеры: ручной ввод с клавиатуры (работает всегда)
  и мост к мод-API игры (автоматически, без ручного ввода).

Платформа: macOS, Steam-версия игры.
