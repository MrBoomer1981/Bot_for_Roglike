# Запуск на Mac: пошагово

Цель — свести первую сессию за Mac к десяти минутам. Всё, что можно было
сделать без игры, уже сделано: клиент к моду написан и отлажен против
фальшивого сервера, справочник из 150 джокеров собран, диагностика готова.

Ниже — только то, что физически требует твоей машины.

## Что проверено, а что нет

Пути, порт и команды взяты из документации мода
[`coder/balatrobot`](https://github.com/coder/balatrobot) и его спецификации
OpenRPC, а не из общих соображений. **Но сам стек на macOS не запускался
никем из нас** — это и есть содержание Фазы 1. Если что-то разойдётся
с описанием, это ожидаемо: пришли вывод, поправим.

## 0. Перед началом

- Balatro обновлён в Steam до последней версии. Steamodded поддерживает
  только актуальную версию — на старой моды не заведутся.
- Установлен `uv`: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Узнай архитектуру: `uname -m` → `arm64` это Apple Silicon, `x86_64` — Intel.
  От этого зависит, какой файл Lovely качать.

## 1. Lovely Injector

Рантайм-инжектор Lua, без него моды не загружаются.
Нужна версия **0.8.0+**, установка — по
[официальной инструкции](https://github.com/ethangreen-dev/lovely-injector#manual-installation).

Для Apple Silicon это архив `lovely-aarch64-apple-darwin`, для Intel —
`lovely-x86_64-apple-darwin`.

## 2. Steamodded

Загрузчик модов, нужна версия **1.0.0-beta-1221a+**,
[инструкция](https://github.com/Steamodded/smods/wiki/Installing-Steamodded-mac).

Каталог модов на macOS:

```
~/Library/Application Support/Balatro/Mods/
```

Если каталога нет — создай. В Finder он скрыт: `Shift-Cmd-.` показывает
скрытые файлы, либо `open ~/Library/Application\ Support/Balatro/`.

**Про достижения.** Steamodded по умолчанию отключает достижения Steam —
это защита от случайной накрутки. Вернуть можно тумблером в игре:
`Mods → config`. Решай осознанно: тумблер снимает защиту и для сид-ранов.

## 3. Мод BalatroBot

Скачай релиз с [releases](https://github.com/coder/balatrobot/releases)
и разложи так:

```
~/Library/Application Support/Balatro/Mods/
├── smods/                # из шага 2
└── balatrobot/
    ├── balatrobot.json
    ├── balatrobot.lua
    └── src/lua/
```

## 4. Запуск игры

Игру надо стартовать **через мод, а не через Steam**:

```bash
uvx balatrobot serve
```

Мод поднимет JSON-RPC сервер на `127.0.0.1:12346`.

Быстрая проверка, что он жив:

```bash
curl -X POST http://127.0.0.1:12346 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "health", "id": 1}'
```

Ожидаемый ответ: `{"jsonrpc":"2.0","result":{"status":"ok"},"id":1}`

## 5. Проверка нашим ботом

Из каталога этого репозитория, когда игра запущена и ты **внутри рана**
(не в главном меню):

```bash
uv run balatro-bot doctor
```

Он покажет фазу, руку, джокеров, блайнд и — главное — скажет, будет ли
расчёт точным. Если игра не запущена, он объяснит, что именно проверить,
а не упадёт с трассировкой.

Пример вывода:

```
связь есть

фаза:        SELECTING_HAND
анте/раунд:  1 / 2
деньги:      $12
блайнд:      Big Blind (BIG), нужно 450
осталось:    рук 3, сбросов 2
рука:        AH KH QH 7C 7D(B) 3S 2S(x) TD(S)
джокеры:
  1. Joker [j_joker]
  2. Blueprint [j_blueprint]
значения рук: от игры

расчёт по этому состоянию будет точным
```

В записи руки скобка — это пометка: `(B)` улучшение Bonus, `(S)` Stone,
`(x)` карта отключена боссом.

## 6. Запись эталонных случаев

Это задача 3a из плана, и она нужна, чтобы движок подсчёта было чем
проверять. Играй как обычно; в момент, когда собираешься разыграть руку:

```bash
uv run balatro-bot record flush-with-blueprint
```

Состояние сохранится в `tests/golden/`. **Разыграй руку и допиши рядом счёт,
который показала игра** — без него случай бесполезен.

Полезнее всего случаи с джокерами, меняющими правила: `Blueprint`, `Mime`,
`Four Fingers`, `Shortcut`, `Smeared Joker`, а также карты с улучшениями
и изданиями.

## Если что-то не работает

| Симптом | Причина |
| --- | --- |
| `Connection refused` | Игра не запущена или запущена через Steam, а не через `uvx balatrobot serve` |
| Моды не грузятся | Lovely или Steamodded поставлены неверно, либо Balatro не обновлён |
| Порт занят | `uvx balatrobot serve --port ДРУГОЙ`, затем `uv run balatro-bot doctor --port ДРУГОЙ` |
| `doctor` пишет «расчёт будет НЕТОЧНЫМ» | Штатно: эффекты джокеров ещё не реализованы, это Фаза 3 |

Пришли вывод `doctor` — по нему видно, что дальше.
